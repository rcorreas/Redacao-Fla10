# Entidades editoriais

Criar fichas para pessoas, clubes, competições, estádios ou organizações quando houver valor recorrente para o trabalho. Não criar fichas por obrigação.

## Conteúdo sugerido
- Nome e identificação inequívoca.
- Contexto estável que costuma ser necessário.
- Datas e fatos históricos com fonte.
- Relações com pautas e reportagens do vault.
- Pontos que precisam de atualização antes de uso.

## Regra de atualização
Dados esportivos dinâmicos — idade, clube atual, contrato, cargo, lesão, números e situação competitiva — devem ser reconfirmados antes de publicação. A ficha é contexto auxiliar, não fonte automática de atualidade.
