# Redação Fla10 — Sistema Editorial

Este repositório contém a base de conhecimento operacional e editorial da Redação Fla10, organizada para uso no Obsidian e versionada pelo Git.

## Objetivo

Preservar e tornar transferível o método de trabalho do projeto: identidade editorial, critérios de apuração, padrões de produção, SEO, formatos de conteúdo, gestão de pautas, memória de decisões e protocolo de colaboração com sistemas de IA.

A documentação deve permitir que uma nova pessoa ou IA compreenda não apenas o que produzir, mas como trabalhar, quais regras respeitar, como verificar informações e como manter a continuidade editorial.

## Como usar

1. Abra a pasta clonada deste repositório como um vault no Obsidian.
2. Comece por [[00 - Sistema/Índice]].
3. Leia [[00 - Sistema/Protocolo de Operação da IA]] antes de produzir ou alterar conteúdo.
4. Consulte a diretriz específica do formato antes de executar o trabalho.
5. Registre decisões duradouras na documentação apropriada e atualize a memória de pautas quando o estado de uma pauta mudar.
6. Versione alterações pelo Git; não trate conversas isoladas como a única fonte de verdade.

## Princípio de manutenção

As regras permanentes devem ficar em documentos estáveis. Notícias, pautas em andamento e decisões temporárias devem ficar em registros próprios, com data e estado. Não duplicar a mesma regra em vários arquivos: manter uma fonte canônica e criar links para ela.

## Estado inicial

Este vault está em fase de estruturação. A documentação inicial estabelece a arquitetura e o protocolo operacional; os manuais específicos serão aprofundados e validados progressivamente com base nas práticas editoriais já consolidadas.
